# Reporting a security concern

Report vulnerabilities privately with **Report a vulnerability** on the repository's [Security tab](https://github.com/rabbit-brain/rb/security/advisories/new). Never describe a security problem in a public issue. Include the rb version, operating system, the affected command or interface, the impact and a minimal reproduction with a synthetic record. Do not send credentials, tokens or a private research record.

If the Security tab does not offer **Report a vulnerability** yet, [open an issue](https://github.com/rabbit-brain/rb/issues/new) that only asks for a private contact, with no details of the problem: no description, version, command or reproduction. A maintainer answers there with a private channel, and the report goes only through it.

For ordinary bugs that do not expose data or cross a security boundary, use a normal issue as described in [CONTRIBUTING.md](CONTRIBUTING.md). [PRIVACY.md](PRIVACY.md) describes the opt-in usage analytics; the manual's rabbitbrain.ai section describes sync.
