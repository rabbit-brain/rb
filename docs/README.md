# Rabbit Brain documentation

The [manual](../AGENTS.md) is the reference for the commands, record format, attribution and rules. It is embedded in each binary: `rb docs` and the MCP resource `rb://docs` return the manual for the installed version. When browsing a release, use that release's Git tag so the documentation matches its package.

| What you need | Start here |
| --- | --- |
| Install rb and try a small project | [README](../README.md), then the `rb tour` command it introduces |
| Record questions, experiments, criteria and evidence | [Manual: a session, start to finish](../AGENTS.md#a-session-start-to-finish) |
| Understand a finding and its limitations | [Manual: reading a finding on its axes](../AGENTS.md#reading-a-finding-on-its-axes) |
| Connect a coding agent or use Python | [Manual: from Python, and over MCP](../AGENTS.md#from-python-and-over-mcp), [agent skill](../SKILL.md) |
| Read or share a record | [Manual: reading the record](../AGENTS.md#reading-the-record) |
| See what rb would write, and take it out again | [Manual: leaving rb](../AGENTS.md#leaving-rb) |
| Hosted login and sync (optional; the service is not open yet) | [Manual: rabbitbrain.ai](../AGENTS.md#rabbitbrainai-optional-rb-login-rb-sync) |
| Validate record files | [JSON Schema](../schema/rb-v1.schema.json), also available locally through `rb schema all` |
| Understand data handling | [Privacy](../PRIVACY.md) |
| Report a problem or contribute | [Contributing](../CONTRIBUTING.md), [security reports](../SECURITY.md) |
| Build or release the package | [Rust implementation](../rust/ARCHITECTURE.md), [releasing](../RELEASING.md) |

The local record and its findings need no hosted account. The browser page generated by `rb page` is a self-contained file; `rb open` serves the local record on your machine. Hosted login and sync are separate from those local reading surfaces; until the hosted service opens, `rb login` and `rb sync` say so and send nothing.
